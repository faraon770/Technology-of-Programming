3. ВХОДНЫЕ И ВЫХОДНЫЕ ДАННЫЕ
================================================================================

ВХОДНЫЕ ДАННЫЕ:
  - x1 (float): координата X первой точки A
  - y1 (float): координата Y первой точки A
  - x2 (float): координата X второй точки B
  - y2 (float): координата Y второй точки B

ВЫХОДНЫЕ ДАННЫЕ:
  - Расстояние между точками A и B (float)
  - Координаты середины отрезка AB: (middle_x, middle_y) (float, float)

================================================================================
4. АЛГОРИТМ РЕШЕНИЯ
================================================================================

Шаг 1: Ввод данных
  - Прочитать координату x1 первой точки A
  - Прочитать координату y1 первой точки A
  - Прочитать координату x2 второй точки B
  - Прочитать координату y2 второй точки B

Шаг 2: Расчет расстояния между точками
  Используем формулу Евклида:
  distance = √((x2 - x1)² + (y2 - y1)²)
  
  Пояснение:
  - Вычислить разницу координат по оси X: dx = x2 - x1
  - Вычислить разницу координат по оси Y: dy = y2 - y1
  - Возвести обе разницы в квадрат: dx² и dy²
  - Сложить квадраты: dx² + dy²
  - Извлечь квадратный корень: √(dx² + dy²)

Шаг 3: Расчет координат середины отрезка
  Используем формулу средних значений:
  middle_x = (x1 + x2) / 2
  middle_y = (y1 + y2) / 2
  
  Пояснение:
  - Сложить x-координаты обеих точек и разделить на 2
  - Сложить y-координаты обеих точек и разделить на 2

Шаг 4: Вывод результатов
  - Вывести координаты точки A
  - Вывести координаты точки B
  - Вывести расстояние между точками
  - Вывести координаты середины отрезка

================================================================================
5. ИСХОДНЫЙ КОД PYTHON
================================================================================

import math

# Ввод координат первой точки A
x1 = float(input("Введите координату x первой точки A: "))
y1 = float(input("Введите координату y первой точки A: "))

# Ввод координат второй точки B
x2 = float(input("Введите координату x второй точки B: "))
y2 = float(input("Введите координату y второй точки B: "))

# Расчет расстояния между точками по формуле Евклида
distance = math.sqrt((x2 - x1)**2 + (y2 - y1)**2)

# Расчет координат середины отрезка AB
middle_x = (x1 + x2) / 2
middle_y = (y1 + y2) / 2

# Вывод результатов
print("\n" + "="*50)
print("РЕЗУЛЬТАТЫ")
print("="*50)
print(f"Точка A: ({x1}, {y1})")
print(f"Точка B: ({x2}, {y2})")
print(f"Расстояние между точками: {distance:.2f}")
print(f"Координаты середины отрезка: ({middle_x}, {middle_y})")
print("="*50)
