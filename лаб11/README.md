# EduJournal — лабораторная работа №11 (вариант 18)

React + Vite. Группа ИС 25-21. 28 студентов. Оценки 0–100.

## Запуск в PyCharm (Windows)

1. Установите Node.js LTS с https://nodejs.org/ (npm устанавливается вместе с Node.js).
2. Распакуйте ZIP. В PyCharm: File → Open → выберите папку `e-journal-react`.
3. Внизу PyCharm откройте вкладку Terminal.
4. Введите `node -v` и `npm -v`. Если команды не найдены — перезапустите PyCharm после установки Node.js.
5. Введите `npm install` (один раз, нужен интернет).
6. Введите `npm run dev`.
7. Откройте адрес из терминала, обычно http://127.0.0.1:5173/ .
8. Остановка: Ctrl+C в терминале.

**Важно:** это React-проект, не Python-программа. Кнопка запуска Python в PyCharm не нужна.

## Файлы

- `src/App.jsx` — главный компонент App, дочерние компоненты StudentRow и Metric, состояние, действия, расчёты.
- `src/students.js` — начальный список студентов.
- `src/style.css` — оформление и адаптация под телефон.
- `src/main.jsx` — подключение React к HTML.
- `index.html` — страница приложения.
- `package.json` — зависимости и команды.

## Возможности

Оценки 0–100, типы работ, изменение и удаление оценок, выбор даты и предмета, посещаемость, средний балл, рейтинг, поиск и сортировка, управление студентами, добавление предметов, история действий, темы, демонстрационный режим просмотра, экспорт CSV (открывается в Excel), автоматическое сохранение в localStorage.

**Ограничения:** данные сохраняются только в браузере на этом устройстве. Режим преподавателя — переключатель интерфейса, НЕ защита паролем. Для настоящей многопользовательской системы необходимы сервер, база данных и авторизация. CSV — не XLSX, но открывается в Excel.

## Проверки вручную

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть приложение | 28 студентов, оценки пустые |
| 2 | Поставить 80 и 100 одному студенту | Средний балл 90.0 |
| 3 | Изменить 80 на 60 | Средний балл 80.0 |
| 4 | Удалить 60 | Средний балл 100.0 |
| 5 | Попытаться ввести 101 или -1 | Оценка не сохраняется |
| 6 | Отметить посещаемость, обновить страницу | Отметка сохранилась |
| 7 | Переключить режим просмотра | Кнопки редактирования скрыты |
| 8 | Скачать CSV и открыть Excel | Данные отображаются |

Это сценарии для самостоятельной проверки, а не утверждение, что они уже пройдены в браузере.

## Как объяснить на защите

`App` — родитель, он хранит массивы студентов, оценок и посещаемости в `useState`. `StudentRow` — дочерний компонент: получает студента, оценки и обработчики через `props`. Когда вызывается `setGrades`, React повторно рисует таблицу и пересчитывает среднее. `localStorage` сохраняет массивы между обновлениями страницы.
